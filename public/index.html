Optimizely Bulk Archive

Clean up old Optimizely Web Experimentation A/B tests, pages and events in bulk. Paste a personal API token and project ID, pick a tab, review what is unused, then archive the ones you don't need - all client-side, nothing stored on a server. Pages and events still referenced by a live experiment are locked so you can't break a running test.

Generate at Account settings → API Access. Save it in your password manager.
